# Getting Started with Multi-Agent_System_CrewAI_Automate-Analyzing_Products_Dataset

## 📋 Prerequisites
- **Python** 3.10+ / **Node.js** 18+
- **Git** & **GitHub CLI**

## ⚡ Quick Start
```bash
# Clone the project repository
git clone https://github.com/chakorabdellatif/Multi-Agent_System_CrewAI_Automate-Analyzing_Products_Dataset.git
cd Multi-Agent_System_CrewAI_Automate-Analyzing_Products_Dataset

# Run the evaluation harness
python scripts/eval_harness.py

# Run the QA test suite
python -m pytest tests/test_monitoring_and_qa.py
```
